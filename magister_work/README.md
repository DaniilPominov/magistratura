# magister_work

Рабочий проект магистерской работы: **диагностика свойств интеллекта по
временным характеристикам речи**.

Это чистая, упорядоченная реорганизация прежнего наброска `voice_signals`:
сначала — рабочий детектор речевой активности (VAD), затем — признаки
временной организации речи, затем — связь этих признаков с результатами
когнитивных тестов.

## Идея в одном абзаце

Речевой сигнал размечается на речь и паузы собственным VAD. По разметке
строятся временные признаки: длительности звуков и пауз, скорость речи,
статистики их распределений, а также нелинейные характеристики
(показатель Хёрста `H` и характерное время `T` по методу нормированного
размаха, энтропийные признаки). Эти признаки образуют вектор на испытуемого;
далее исследуется его связь с уровнем интеллекта (тесты Айзенка) — развитие
подхода Кузенкова/Пака/Французенко.

## Этапы

| Этап | Содержание | Статус |
|-----|------------|--------|
| **1. VAD** | Детектор речи/пауз: energy-база, энтропийный детектор Кузенкова, метрики, синтетика | ✅ каркас работает |
| **2. Признаки** | Временные + нелинейные признаки речи на испытуемого | 🟡 частично (H/T есть) |
| **3. Связь с IQ** | Модель связи признаков с когнитивными тестами | ⏳ после Этапа 2 |

Подробно: [docs/00-proposal.md](docs/00-proposal.md).

## Быстрый старт

Требуется Python 3.13 (для него есть готовый wheel PyYAML).

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest                       # 22 теста
python scripts/run_vad.py <файл.wav>   # energy + entropy VAD
```

## Структура

```
magister_work/
  src/speechdyn/
    contracts.py     # SegmentRecord, таксономия, разбиение
    framing.py       # TimeGrid, RMS-кадры, параболическая огибающая
    wav.py           # чтение mono 16-bit PCM WAV
    config.py        # YAML + хеш конфигурации
    metrics.py       # precision/recall/F1/IoU/false_pause_precision
    dynamics.py      # modified R/S: H, T (варианты A и C)
    synthetic.py     # синтетический генератор для тестов
    vad/
      base.py        # VadBackend, states -> отрезки
      energy.py      # EnergyVad (гистерезис)
      entropy.py     # EntropyVad (энтропия фазового пространства)
  scripts/run_vad.py
  tests/test_stage1.py
  configs/default.yaml
  wiki/              # исходные статьи и их Markdown-извлечения
  docs/              # план, спецификация этапа, идеи
```

## Переиспользование `voice_signals`

Из прежнего проекта перенесены и облегчены: контракт сегмента, framing и
огибающая, energy VAD, modified R/S (H, T). Убраны: избыточные слои
аудита/feature-extractor, экспериментальная обвязка. `voice_signals` остаётся
как архив и источник методики, но не как активная зависимость.
