## О содержании

- **Диагностика свойств интеллекта…** — связь временных характеристик речи
  (длительности звуков и пауз) с уровнем интеллекта; тесты Айзенка, метод
  главных компонент, линейная модель оценки IQ. PDF — только изображения
  (ABBYY FineReader), поэтому текст получен OCR и может содержать ошибки
  распознавания.
- **Метод нормированного размаха…** — модификация R/S-анализа: показатель
  Хёрста `H` и характерное время `T` для рядов мощностей речи при афазиях и
  дизартрии. Опорная методика для статистической ветви проекта `voice_signals`.
- **Нейроинформатика 2021** — сборник материалов семинара (YOLOv4/DeepSORT,
  упругие карты, спайковые сети и др.).

## Как пересобрать

Извлечение выполняет скрипт [`tools/pdf2md.py`](tools/pdf2md.py). Он сам
определяет, есть ли в PDF текстовый слой, и при необходимости запускает OCR
(Tesseract, языки `rus+eng`). Требуется PyMuPDF и установленный Tesseract.

```powershell
python tools/pdf2md.py
```

Файлы кладутся рядом с исходными PDF в `docs/`. Языки OCR подбираются
автоматически из доступных `*.traineddata`.
