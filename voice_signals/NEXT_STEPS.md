### 1. TASK-06 полная: WebRTC VAD адаптер

**Цель:** Реализовать baseline для сравнения

**Задачи:**

**Оценка:** 1-2 дня

### 2. TASK-03: DFA-Hurst (сравнение с modified R/S)

**Цель:** Проверить согласованность двух методов оценки H

**Задачи:**
- Реализовать Detrended Fluctuation Analysis
- Сравнение на синтетических рядах с известным H
- Корреляция DFA-H vs modified R/S-H
- Документация различий

**Оценка:** 2-3 дня

---

### 3. Реализовать subject-level split

**Цель:** Подготовить алгоритм для честной валидации

**Задачи:**
- Функция `split_by_subject_id(files, split_ratios=(0.6, 0.2, 0.2), seed=42)`
- Стратифицированный split (сохранение баланса классов)
- Проверка: нет пересечений subject_id между train/validation/test
- Unit-тесты

**Оценка:** 1 день

---

### 4. TASK-08 подготовка: Инструкция разметки

**Цель:** Подготовить документацию для аннотаторов

**Задачи:**
- Написать инструкцию разметки:
  - Таксономия и определения
  - Правила для пограничных случаев
  - Примеры (с картинками спектрограмм)
- Настроить Label Studio локально
- Создать конфиг разметки (XML)
- Реализовать конвертеры Label Studio JSON → SegmentRecord

**Оценка:** 2-3 дня

**Примечание:** Финальная версия требует согласования с научруком

---

### 5. Реализовать метрики качества

**Цель:** Подготовить код для оценки VAD

**Задачи:**
- `false_pause_precision` (первичная метрика)
- `speech_recall`, `hesitation_recall`
- `pause_duration_bias`
- IoU (Intersection over Union) для временных сегментов
- Segment F1 (с tolerance ±100 мс)
- Latency (задержка детекции)
- Функции в `src/voice_signals/metrics.py`
- Unit-тесты на синтетике

**Оценка:** 2 дня

## 🎯 КРИТЕРИИ ГОТОВНОСТИ MVP

MVP считается готовым, если:

- ✅ Нет пересекающихся сегментов
- ✅ Все времена в пределах файла
- ✅ Повреждённый WAV не роняет батч
- ✅ Отчёты воспроизводимы по seed и config hash
- ✅ Train/validation/test разделены по subject_id
- ✅ Собственный VAD сравнён с Energy и WebRTC на одном test split
- ✅ Synthetic и real-data качество явно разделены
- ✅ Есть статистическая проверка улучшений (permutation test, bootstrap CI)
