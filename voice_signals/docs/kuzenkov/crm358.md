# Использование метода нормированного размаха при анализе речевых патологий неврологического генеза

## Введение
Речь человека является главным средством коммуникации и играет ключевую роль во всех социально значимых действиях. Кроме того, именно на основе речи формируются и реализуются многие интеллектуальные процессы человека. Диапазон речевых нарушений довольно широк и простирается от едва различимых искажений звукопроизношения до полной утраты всех речевых функций, включая понимание устной и письменной речи. При этом возникшее в результате действия каких-либо травмирующих факторов речевое нарушение обычно не проходит самостоятельно, а требует продолжительной и кропотливой логопедической работы. В силу этих причин реабилитация больных с различными речевыми патологиями имеет большое социальное значение. Одним из важных аспектов реабилитации является эффективная и объективная диагностика текущего состояния больного. Диагностика должна не только фиксировать факт наличия речевых патологий, но и предоставлять шкалу оценки состояния этих патологий, основанную на результатах инструментальных измерений.

Использование инструментальных оценок речевых параметров в совокупности с различными математическими методами применяется при решении широкого круга задач. Подходы, используемые при решении этих задач, обычно разделяют на две группы:
1. **Моделирование функциональных частей:** строятся модели какой-либо функциональной части речевого аппарата по речевому сигналу через решение обратных задач.
2. **Формальный анализ:** акцент делается на формальном применении методов анализа (спектр, кепстр, вейвлет-преобразование, функция распределения вероятностей) с их последующей статистической обработкой.

Данная работа придерживается преимущественно второго подхода и посвящена исследованию статистических характеристик показателя Хёрста в группах с речевыми патологиями по типу моторных афазий, нейродинамических афазий и дизартрий у взрослых в сравнении с нормой.

## Клинический материал
Речь человека представляет собой продукт работы речевого аппарата и специальных структур головного мозга. Условно указанные структуры подразделяют на центральный (головной мозг) и периферический (легкие, гортань, надставная труба, нервные пути) отделы.

Исследуемые патологии:
* **Моторные афазии (афферентная и эфферентная):** связаны с нарушением временной организации речевых высказываний при поражении коры головного мозга.
* **Нейродинамические афазии:** вызваны поражением глубинных подкорковых структур. Характерны флуктуации проявлений и значительный потенциал к восстановлению.
* **Дизартрия:** грубое нарушение моторной динамики и расстройство артикуляции при сохранной грамматической и лексической структуре.

**Параметры записи:**
* Текст: рассказ А. П. Чехова «Злой мальчик» (чтение и пересказ).
* Оборудование: электродинамический микрофон, частота дискретизации $\nu = 8$ кГц.
* Предобработка: фильтрация (ФВЧ 80 Гц, 24 дБ), удаление постоянной составляющей, нормировка амплитуды до 1.
* Объем выборки: 429 образцов (суммарное время 23 ч 56 мин).

## Модификация алгоритма вычисления показателя Хёрста
Классическая схема R/S-анализа оперирует следующими понятиями для временного ряда $x(t_i)$ на интервале $\tau$:
* Среднее значение: $\bar{x}(\tau) = \frac{1}{\tau} \sum_{i=1}^{\tau} x(t_i)$
* Стандартное отклонение: $S(\tau) = \sqrt{\frac{1}{\tau} \sum_{i=1}^{\tau} (x(t_i) - \bar{x}(\tau))^2}$
* Накопившееся отклонение: $X(t, \tau) = \sum_{j=1}^{t} (x(j) - \bar{x}(\tau))$
* Размах: $R(\tau) = \max_{1 \le t \le \tau} X(t, \tau) - \min_{1 \le t \le \tau} X(t, \tau)$

Эмпирический закон Хёрста:
$$ \frac{R(\tau)}{S(\tau)} = \left( \frac{\tau}{2} \right)^H $$
где $H$ — показатель Хёрста. $H = 0.5$ соответствует броуновскому движению, $0.5 < H < 1.0$ — персистентному ряду (наличие памяти), $0 < H < 0.5$ — антиперсистентному.

**Проблемы классического алгоритма:**
1. Экспоненциальное увеличение плотности отсчетов в логарифмической шкале.
2. Зависимость от начальной фазы сигнала.
3. Высокая вычислительная сложность $O(N^2)$ при сплошном переборе $\tau$.

**Предложенная модификация:**
Шкала $\tau$ реализуется в виде геометрической прогрессии: $\tau_1 = 3$, $\tau_i = a \cdot \tau_{i-1}$, где $a = \left( \frac{N}{3} \right)^{\frac{1}{n-1}}$. Ряд разбивается на $k$ пересекающихся интервалов с последующим усреднением $R/S$. Это обеспечивает равномерный шаг в логарифмических координатах, снижает чувствительность к фазе и уменьшает сложность до $O(n \cdot N)$.

## Заключение
Наличие речевой патологии приводит к достоверному изменению значений показателя Хёрста и/или характерного времени. Метод уверенно отличает нейродинамическую афазии от нормы, что является важным результатом, так как клинически она часто схожа с моторными афазиями. Для повышения эффективности диагностики метод следует применять в комбинации с другими подходами. Алгоритмически модификация наиболее перспективна для длинных нестационарных рядов.

## Приложение: Реализация алгоритма (Scilab 5.5.0)

```scilab
function y = avrRSsetRange(s, n1, n2, L)
    // s - анализируемый временной ряд
    // n1, n2 - нижняя и верхняя границы интервала (в отсчетах)
    // L - количество вычисляемых значений нормированного размаха
    
    winH = waitbar(0);
    t = zeros(L, 1);
    x = zeros(L, 1);
    N = length(s);
    
    // Геометрическая прогрессия для шкалы tau
    a = (n2 / n1)^(1 / (L - 1));
    t(1) = n1;
    for i = 2:L
        t(i) = a * t(i - 1);
    end;
    
    for i = 1:L
        t1 = floor(t(i));
        t2 = ceil(t(i));
        
        // --- Вычисление для t1 ---
        k = fix(N / t1) + 1;
        delta = N / (2 * k);
        pos = zeros(k, 1);
        pos(1) = delta;
        for j = 2:k
            pos(j) = pos(j - 1) + 2 * delta;
        end;
        
        borders = zeros(k, 2); // Исправлено с 'boroders'
        for j = 1:k
            borders(j, 1) = floor(pos(j) - delta) + 1;
            borders(j, 2) = borders(j, 1) + t1 - 1;
        end;
        
        if borders(k, 2) > N then
            tt = borders(k, 2) - N;
            borders(k, 1) = borders(k, 1) - tt;
            borders(k, 2) = borders(k, 2) - tt;
        end;
        
        x1 = 0;
        for j = 1:k
            x1 = x1 + RS(s(borders(j, 1):borders(j, 2)));
        end;
        x1 = x1 / k;
        
        // --- Вычисление для t2 ---
        k = fix(N / t2) + 1;
        delta = N / (2 * k);
        pos = zeros(k, 1);
        pos(1) = delta;
        for j = 2:k
            pos(j) = pos(j - 1) + 2 * delta;
        end;
        
        borders = zeros(k, 2);
        for j = 1:k
            borders(j, 1) = floor(pos(j) - delta) + 1;
            borders(j, 2) = borders(j, 1) + t2 - 1;
        end;
        
        if borders(k, 2) > N then
            tt = borders(k, 2) - N;
            borders(k, 1) = borders(k, 1) - tt;
            borders(k, 2) = borders(k, 2) - tt;
        end;
        
        x2 = 0;
        for j = 1:k
            x2 = x2 + RS(s(borders(j, 1):borders(j, 2)));
        end;
        x2 = x2 / k;
        
        // Линейная интерполяция
        if t2 == t1 then
            x(i) = (x1 + x2) / 2;
        else
            x(i) = x1 + (x2 - x1) * (t(i) - t1) / (t2 - t1);
        end;
        
        waitbar(i / L, 'Computing, please wait...', winH);
    end;
    
    y(:, 1) = t;
    y(:, 2) = x;
    close(winH);
endfunction

function y = RS(x)
    lx = length(x);
    avrx = sum(x) / lx;
    devx = x - avrx;
    xcum = cumsum(devx);
    stdx = (sum(devx.^2) / lx)^0.5;
    
    if stdx ~= 0 then
        y = (max(xcum) - min(xcum)) / stdx;
    else
        y = 0;
    end;
endfunction
```
