# Human Action Recognition in Video Data Based on Deep Learning Methods

Источник: [030020_1_5.0301806.pdf](../030020_1_5.0301806.pdf)  
Библиография: Shaimaa H. Shaker, Ammar Fakhri Mahdi, Rehab F. Hasan, Raghad Abdulaali Azeez. *AIP Conference Proceedings* 3395, 030020 (2025). DOI: `10.1063/5.0301806`.

## Что изучает статья

Обзор vision-based human activity recognition (HAR): классических признаков, deep learning, гибридных и modality/view-invariant архитектур, а также semi-supervised learning. Статья ориентирована на распознавание действий в видео, а не на VAD и не на аудио.

## Полезные идеи

- Типовой конвейер: сбор данных -> предобработка -> сегментация -> извлечение признаков -> классификация.
- Классические методы используют optical flow, motion history image, локальные/глобальные дескрипторы и SVM; их плюс — интерпретируемость и меньшая вычислительная стоимость.
- CNN/3D-CNN/ConvLSTM автоматически извлекают пространственно-временные признаки, но требуют больше размеченных данных и вычислений.
- Semi-supervised learning рассматривается как способ использовать большой объём неразмеченных видео при дорогой ручной разметке.
- В качестве ориентиров приведены датасеты NTU-RGB+D, MSR-Daily Action, UCF101 и другие; в таблице статьи указаны, например, 86.42% для CNN на NTU-RGB+D, 92.90% для FWMDMM на MSR-Daily Action и 89.00% для S-CNN на UCF101. Эти числа нельзя сравнивать напрямую без проверки протокола split и метрики.
- Для устойчивости авторы рекомендуют гибридные архитектуры и проверку на изменениях ракурса, фона, окклюзиях и неполной разметке.

## Что перенести в `voice_signals`

1. Использовать схему «сегментация -> признаки -> классификация» как организационный шаблон для аудиопайплайна, не перенося video-признаки буквально.
2. Рассмотреть semi-supervised обучение только после появления стабильного gold-набора: псевдоразметка не должна заменять subject-level test.
3. В отчётах явно разделять handcrafted baseline и learned representation; сравнивать их на одном split и одних и тех же временных окнах.
4. Воспользоваться идеей оценки устойчивости: отдельные срезы по шуму, условиям записи и респондентам аналогичны срезам по сцене/ракурсу в видео HAR.

## Ограничения и критическая оценка

- Это обзор, а не единый воспроизводимый эксперимент; приведённые accuracy зависят от конкретных датасетов и протоколов.
- В тексте есть редакционные и терминологические неточности, поэтому таблицы статьи следует использовать как указатели литературы, а не как проверенный benchmark.
- В статье недостаточно деталей для прямого воспроизведения preprocessing и split.
- Для текущего проекта нельзя делать выводы о когнитивных характеристиках по результатам HAR; максимум — использовать идеи для инженерного VAD и последующего анализа.

## Решение для проекта

Приоритет: **средний**. Полезно для дизайна экспериментов с малой разметкой и robustness-матрицы, но не является источником параметров текущего energy/WebRTC VAD.
