# TASK-03. Показатель Хёрста через DFA

Роль: Nonlinear dynamics agent. Файл результата: `hurst_dfa.py`.

## Цель
Устойчивый расчёт показателя Хёрста для рядов из речевого сигнала. Показатель — дескриптор структуры сигнала, а не доказательство когнитивного процесса.

## Вход
Одномерный ряд: energy envelope, log-energy envelope, spectral flux, первая компонента Mel, pitch contour (если стабилен). Параметры: window_sec, hop_sec, min_points, scale_range.

## Выход
Для каждого окна: start_sec, end_sec, hurst_exponent, fit_r_squared, n_points, validity_flag, warning_flags.

Агрегаты по валидным окнам: hurst_mean, hurst_median, hurst_std, hurst_p10, hurst_p90, hurst_valid_ratio.

## Метод
DFA: профиль ряда (интегрирование после центрирования), разбиение на окна размера s, линейный детрендинг в каждом окне, F(s) = sqrt(mean((x - f)^2)), регрессия log F(s) по log s, наклон = H.

Агент обязан явно задокументировать, применяется ли метод к fGn или fBm.

## Шаги
1. `dfa_hurst(series, scales, detrend_order=1)` -> hurst, r_squared, n_scales_used, warnings.
2. `sliding_hurst(series, sample_rate, window_sec, hop_sec)`; при недостатке точек — NaN и validity_flag=False.
3. Масштабы: min_scale 4 или 8 точек, max_scale = window_length / 4, логарифмическая сетка; конфигурируется.
4. Детрендинг: линейный; полиномиальный порядок 2 как опция.
5. Валидность отрицательна при: r_squared < 0.8, менее 4 масштабов, слишком много тишины, дисперсия около нуля.
6. Агрегация только по валидным окнам.

## Критерии приёмки
1. На синтетическом fGn с известным H: |H_est - H_true| < 0.10 на длинных рядах.
2. На белом шуме оценка около 0.5.
3. На постоянном сигнале — validity=False, без случайного числа.
4. На коротких окнах нет мусорных значений.
5. Воспроизводимость при фиксированном seed.

## Тесты
- fGn H = 0.25, 0.5, 0.75.
- Белый шум, случайное блуждание, постоянный сигнал, периодический сигнал, ряд с трендом.
- Статистика: 50 реализаций fGn, распределение ошибок.
- Интеграция: log-energy envelope синтетической речи, окна согласованы по времени с сегментами.

## Ошибки, которых избегать
- Смешивать fGn и fBm без объяснения.
- Слишком мало масштабов.
- Не проверять R^2.
- Считать H доказательством когнитивного процесса.
- Применять DFA к очень коротким сегментам и трактовать результат как устойчивый.

## Инструкция агенту
Реализуй расчёт Хёрста методом DFA: скользящие окна, выбор масштабов, линейный детрендинг, R^2 и флаги валидности. Протестируй на fGn с известным H. Явно укажи, применяется ли метод к fGn или fBm. Не возвращай числа для коротких или вырожденных рядов.
