# Глобальные правила для всех ИИ-агентов

Эти правила должны вставляться в контекст каждому агенту.

## Правило 1. Не выдумывать свойства реального датасета

Пока данные не получены, все предположения о частоте дискретизации, длительности, количестве файлов и метаданных должны маркироваться как допущение.

Формат маркировки:

```text
ASSUMPTION: ...
UNKNOWN: ...
TODO_AFTER_DATA_AUDIT: ...
```

## Правило 2. Работать сначала на синтетических и публичных данных

Любой модуль должен быть проверяем до получения реального корпуса. Для этого используется синтетический генератор речи, пауз, гезитаций, дыхания и артефактов.

## Правило 3. Не передавать сырое аудио во внешние сервисы без явного разрешения

Даже если технически допустимо использовать облачные ASR или VAD-сервисы, по умолчанию действует ограничение:

```text
RAW_AUDIO_EXTERNAL_UPLOAD = forbidden_until_legal_review
```

ИИ-агенту разрешается работать с:

- синтетическими данными;
- анонимизированными метаданными;
- признаковыми матрицами;
- результатами локальной обработки.

Сырое аудио реальных респондентов не должно выгружаться агенту или во внешний сервис без подтверждения этического и правового статуса.

## Правило 4. Все числовые модули должны иметь детерминированные тесты

Каждый алгоритмический компонент должен проверяться на сигналах с известным поведением:

- синус;
- белый шум;
- розовый шум;
- дробный гауссовский шум;
- хаотический ряд;
- периодический сигнал;
- речеподобные сегменты;
- тишина;
- транзиентные шумы.

## Правило 5. Не смешивать техническую задачу VAD и когнитивную задачу

На этапе реализации сегментатора нельзя формулировать результаты как «модель определяет интеллект». Корректная формулировка:

```text
Модель сегментирует речевые события.
Полученные признаки могут использоваться для дальнейшего исследования ассоциаций с результатами когнитивных тестов.
```

## Правило 6. Любой change должен быть привязан к метрике

Если агент меняет архитектуру, признаки, пороги или постобработку, он обязан указать, какая метрика проверяется:

```text
false_pause_precision
hesitation_recall
pause_duration_bias
macro_F1
calibration_ECE
downstream_Spearman
```
